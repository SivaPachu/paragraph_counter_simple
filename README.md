# 📝 Paragraph Counter – Type. Count. Track.

Paragraph Counter is a simple, modern, and responsive web application designed to count the number of characters entered by the user. The project focuses on implementing real-time character counting using JavaScript along with a clean and responsive user interface using HTML5 and CSS3.

The application allows users to enter up to 200 characters, displays the number of characters written and remaining in real time, and provides a reset button to completely clear the text and reset the counters.

## 📄 Website Features
### 📝 Paragraph Input
- Textarea for entering paragraph content
- Placeholder text for user guidance
- Supports multiline text input
- Maximum limit of 200 characters

### 🔢 Character Counter
- Displays the number of characters written
- Calculates the remaining characters
- Updates the counter in real time
- Prevents the user from exceeding 200 characters

---

### 🔄 Reset Function
- Clears all entered text
- Resets written characters to 0
- Resets remaining characters to 200

---

### 📱 Responsive Design
- Responsive paragraph counter card
- Mobile-friendly layout
- Flexible textarea and content sections
- Media queries for different screen sizes
